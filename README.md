This project presents an interactive Zepto Sales Dashboard developed in Microsoft Excel to analyze sales performance, customer behavior, product trends, and 
revenue insights. The dashboard transforms raw sales data into meaningful visualizations that support data-driven decision-making.
Objectives of this project
Monitor overall sales performance.
Analyze revenue, profit, and order trends.
Identify top-performing products and categories.
Track customer purchasing patterns.
Discover business growth opportunities through data analysis.
Enable stakeholders to make informed decisions using interactive visuals.
